# OmniCustomer Tech Support Manual & Return Policy

## 1. Troubleshooting Wi-Fi Issues
If a customer reports a broken Wi-Fi router or connectivity issues, please advise them to follow these exact steps:
1. Unplug the router from the wall outlet and wait exactly 60 seconds.
2. Plug the router back in and wait for the "Internet" LED light to turn solid green.
3. If the router light blinks amber, the hardware has failed. Please authorize a free replacement.
4. If the light is green but the internet still fails, please instruct them to call their ISP directly.

## 2. Refund and Return Policy
* **Standard Return Window**: 30 days from the date of delivery.
* **Damaged Items**: If an item arrives damaged, the customer is entitled to a full 100% refund without returning the item.
* **Restocking Fee**: A 15% restocking fee applies to all open-box electronics.

## 3. Escalations
If an issue cannot be resolved using these documents, all agents must immediately escalate the ticket to a human manager. Under no circumstances should an agent invent troubleshooting steps.
