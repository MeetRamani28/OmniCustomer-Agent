# OmniCustomer-Agent

An ultra-advanced, enterprise-grade autonomous multi-agent customer operations platform setting a new gold standard for production software engineering. This repository demonstrates absolute mastery over distributed systems, agentic state graphs, and fault-tolerant cloud architecture.

## 🚀 Enterprise Tech Stack

### Core AI & Agent Engine
- **Orchestration:** `@langchain/core` & `@langchain/langgraph` (Stateful Multi-Agent Swarms)
- **Local Dev Models:** Cohere / Mistral AI 
- **Production Models:** Groq LLM (Ultra-low latency inference)
- **Retrieval Architecture:** Parent-Child Chunking, Hybrid Search (Keyword FTS + Vector Cosine Similarity with RRF)

### Backend Infrastructure
- **Server:** Node.js, Express.js, TypeScript (ESM), Socket.io (Real-time Event Bus)
- **Local Storage:** Better-SQLite3
- **Cloud Database:** Supabase (PostgreSQL with `pgvector`)
- **Distributed Vector Search:** Pinecone Cloud
- **Media Persistence:** Cloudinary Cloud Assets
- **Security:** LlamaGuard Zero-Trust Firewall, PII Tokenization Vault

### Frontend Architecture
- **Framework:** React 19, Vite, TypeScript
- **Styling:** Tailwind CSS v4, Lucide React
- **State Management:** TanStack React Query (v5), React Context API
- **Real-Time Integration:** Socket.io-client
- **UI/UX:** Production-grade chat UI with Markdown Rendering and Toast notifications

## 🛡️ Security & Zero-Trust
Strict separation of concerns. Local development utilizes `.env` with localized free-tier keys, gracefully migrating to secure production cloud configurations with Courier webhooks and zero-trust policy boundaries.
